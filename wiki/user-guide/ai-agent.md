# 通过 AI Agent（MCP）自然语言编排

> 不想拖拽画布？你可以用日常语言描述需求，让 AI 编程助手（Agent）帮你搭好、校验并运行工作流。架构背景见 [系统总览](../architecture/overview.md)。

## 1. 这是什么？

Flow Engine 暴露了一个 **MCP（Model Context Protocol）服务**，主流 AI 编程助手都能接入，例如：

- **Claude Code**
- **Cursor**
- **VS Code（含 Copilot / Claude 类扩展）**
- **Claude Desktop**

接入后，你只需用**自然语言**告诉助手"我想做什么"，它就调用 Flow Engine 的工具去：发现可用节点 → 装配工作流 → 校验 → 请你确认 → 执行。你不必自己拖节点、连线、填参数。

## 2. 第一步：拿到现成的 MCP 配置

1. 先在网页端**登录** Flow Engine。
2. 打开 **帮助与 MCP 配置** 页面（顶部"帮助"入口）。
3. 页面上已为你**生成好一份完整的 MCP 配置**，其中已经包含了你的 **API Key**，无需自己申请或拼接。
4. 点击**复制**该配置。

> 该页面同时提供可复制的 MCP 配置块，复制即含凭据，省去手动配置。

## 3. 第二步：把配置交给你的 Agent

将复制到的配置，按你使用的助手的方式粘贴进去：

- **Claude Code / Cursor / VS Code**：放入对应 MCP 配置文件（如 `settings` / `.mcp.json` / 扩展的 MCP 设置）中。
- **Claude Desktop**：放入其 MCP 配置项里。

具体放哪个文件因工具而异，但内容都用刚才复制的那一段即可。配置好后，助手就能"看到" Flow Engine 的能力了。

## 4. 第三步：用自然语言描述你的工作流

在助手对话里直接说需求，例如：

> "每天早上 9 点从某某接口拉取数据，如果状态是 error 就发钉钉通知，否则存进数据库。"

助手会：

1. **发现节点**（列出可用的 HTTP、If、通知、DB 等节点）；
2. **装配工作流**（生成节点与连线草案）；
3. **校验**（检查参数、连线是否合法，给出错误并修正）；
4. **请你确认**（草案就绪后，会请你 review / 批准，避免误操作）；
5. **执行 / 激活**（你确认后，它可帮你运行或激活工作流）。

整个过程你主要做"描述 + 确认"，复杂的编排交给助手。

## 5. 凭据怎么处理？

涉及密钥 / Token 的节点，AI 助手会**按凭据 ID 引用**你在 [凭据管理](credentials.md) 中创建的凭据，而不是把明文写进工作流。你只需提前在网页端建好凭据，助手在装配时选择对应 ID 即可。

## 6. 适合的场景

- 不熟悉画布操作，想快速把想法变成可用流程；
- 流程较复杂，希望助手帮忙检查参数与连线是否正确；
- 需要反复修改，用自然语言迭代比手动拖拽更快。
