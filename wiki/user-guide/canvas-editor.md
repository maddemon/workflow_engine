# 用画布编排工作流

> 本文介绍如何在网页画布上搭建工作流。背景架构可参考 [系统总览](../architecture/overview.md)。

## 1. 打开画布

登录后进入工作流列表，新建或打开一个工作流，即可进入**画布编辑器**（Workflow Editor）。界面大致分为三块：

- **左侧节点面板**：可选节点的清单，按类别分组。
- **中央画布**：拖放节点、连线的主要区域。
- **右侧参数面板**：选中某个节点后，自动出现该节点的配置项。

## 2. 从节点面板拖出节点

左侧面板里的节点来自后端提供的节点目录（`GET /api/node-types`，由已安装的插件决定，例如 HTTP、Code、If、Loop、Merge、Agent、LLM、DB 等）。

操作：

1. 在左侧找到需要的节点。
2. 按住拖到中央画布上松开，节点就放置好了。
3. 重复添加所需的所有节点。

> 节点清单由服务器上安装的插件决定。如果想要的节点没出现，可能是对应插件未安装，需要联系管理员。

## 3. 连线：把节点串起来

每个节点上有一些**端口（Port）**——通常是上方的"输入"和下方的"输出"。

- **连接**：在某个节点的输出端口上按住，拖到下一个节点的输入端口松开，即建立一条数据流向。
- **分支**：像 `If` 这类节点会有多个输出端口（例如"真 / 假"），分别连到不同后续节点，实现条件分支。
- **删除连线**：选中一条线后按删除（或点击线上的删除操作）即可断开。

连线方向就是数据流动方向，请按照"谁先处理、结果给谁"的逻辑连接。

## 4. 配置节点参数

点击画布上的节点，右侧**参数面板**会根据该节点的定义自动生成对应的配置表单。

- **必填校验**：带"必填"标记的项必须填写，未填时表单会提示，且通常无法保存/运行。
- **条件显隐**：某些字段只在特定选项下才出现。例如选择了某类认证方式后，才显示相关的账号字段。面板会按节点声明自动显隐，无需手动处理。
- **凭据引用**：涉及密钥/令牌的字段，通常是一个下拉选择，直接选择你在[凭据管理](credentials.md)里建好的凭据，而不是把明文填进表单。

填写完成后，参数会自动随工作流保存。

## 5. 撤销 / 重做

画布支持操作历史：

- **撤销（Undo）/ 重做（Redo）**：通过工具栏上的撤销 / 重做按钮（`CanvasToolbar` 中的 `Undo2` / `Redo2` 图标）操作。当前画布快捷键仅绑定了复制 / 粘贴（`Ctrl/Cmd+C` / `Ctrl/Cmd+V`，见 `WorkflowCanvas.tsx:213`），**撤销暂未绑定键盘快捷键**，只能点工具栏按钮。
- **重做（Redo）**：恢复被撤销的操作。

建议每次较大改动后留意保存状态，重要调整可先撤销验证再继续。

## 6. 保存工作流

编排完成后记得**保存**。保存后工作流才会在列表里更新，也才能被触发器调度或手动运行。
