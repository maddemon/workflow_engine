# 产品简介

> 本文面向**最终用户**（通过浏览器使用 Flow Engine 的人），不涉后端技术细节。想了解系统架构可看 [系统总览](../architecture/overview.md)。

## 1. Flow Engine 是什么？

Flow Engine 是一个**可视化工作流自动化工具**。

你不需要写代码，只要在网页画布上把一个个功能"节点"拖出来、用线连起来，就能让系统按你设计的顺序自动完成一系列任务——比如"定时从某个接口拉数据 → 判断结果 → 发送通知"。

- **节点（Node）**：一个最小的功能单元，例如"发送 HTTP 请求""执行一段判断""调用 AI""读写数据库"。每个节点只做一件事。
- **连线（Edge）**：把节点的输出接到下一个节点的输入，数据就顺着线流动。
- **工作流（Workflow）**：由节点和连线组成的完整自动化流程。

## 2. 你是怎么使用它的？

Flow Engine 运行在一台服务器上，你只需用**浏览器**打开网页即可使用，无需安装任何软件。

典型的使用路径：

1. 在**画布编辑器**里拖出节点、连线，搭好工作流。
2. 在**参数面板**里填写每个节点需要的配置（如请求地址、判断条件）。
3. 如果节点需要账号密码之类的敏感信息，在**凭据管理**里创建，节点按"引用"使用，明文不暴露。
4. 配置**触发器**（定时 / Webhook / 轮询），让工作流自动运行；也可以随时手动点"运行"。
5. 在**执行与监控**页面实时看节点跑到哪一步、每一步输出了什么。

## 3. 几种使用方式

| 方式 | 适合谁 | 说明 |
|------|--------|------|
| 网页画布 | 所有人 | 拖拽式可视化编排，本文档重点。 |
| AI Agent（MCP） | 想用自然语言描述需求的人 | 把需求告诉 AI 助手（如 Claude / Cursor），由它帮你装配和验证工作流，详见 [通过 AI Agent 编排](ai-agent.md)。 |
